OVERWATCH

Run N agents. Watch 1 window.
Overwatch detects when any session gets blocked, summarizes why, and lets you respond — without switching terminals.

How It Works

AI agents block constantly. Overwatch makes sure you never miss it.

1

Create Sessions

Launch Claude, Kiro, or any CLI agent in a named session with a goal and working directory.

2

Agents Work

Sessions run in parallel PTYs. Overwatch monitors output and detects blocked states automatically.

3

Get Notified

When an agent gets stuck, Bedrock Claude summarizes what it needs — one line, no terminal diving.

4

Respond Once

Approve, redirect, or delegate to the Overwatch orchestrator. All from a single pane.

🖥️

Multi-Agent Sessions

Run Kiro, Claude, or any CLI agent in parallel tabs. Each session gets its own terminal with full PTY support.

🧠

AI Orchestrator

A supervisor agent that delegates tasks, monitors progress, and coordinates work across sessions — so you don't have to babysit.

🔔

Smart Notifications

LLM-powered summarization of blocked events. Know exactly why an agent is stuck with a single glance.

🔌

MCP Server

Exposes session management via Model Context Protocol on localhost:3777. Plug in Claude Code, your own orchestrators, or any MCP-compatible agent.

🔍

Stuck Detection

Detects idle timeouts, repeated errors, output loops, and approval prompts. Sessions transition to blocked state automatically.

🔧

MCP Client

Connect any MCP server to extend the orchestrator's capabilities. Add your own tools, file systems, or APIs.

🔄

Session Resume

Sessions persist across restarts. Agents resume conversations where they left off. Terminal scrollback is preserved.

🎨

Themeable UI

5 built-in themes with Obsidian default. Resizable panes, collapsible panels, and persistent layout.

⚡

Event-Driven

Blocked events are injected into the orchestrator's context with session and tab IDs — enabling autonomous intervention.
